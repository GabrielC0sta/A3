Sobre o Projeto

Este projeto foi criado com o objetivo de informar de forma moderna e interativa sobre os 17 Objetivos de Desenvolvimento Sustentável (ODS) da ONU. A proposta une tecnologia, design atrativo e conteúdo educacional em uma experiência acessível e envolvente.

1. Motivação e Criação

Desde o início, a ideia era fugir do comum. Em vez de uma apresentação estática, optamos por um site dinâmico e atrativo que educasse ao mesmo tempo que impressionasse visualmente.

Todo o layout foi desenvolvido com atenção aos detalhes: cores vivas, animações suaves, responsividade total e uso inteligente de multimídia. O desenvolvimento envolveu:

  • Planejamento da navegação e fluxos entre as páginas
  • Desenho de uma identidade visual futurista com gradientes e neons
  • Construção modular e reutilizável dos estilos e scripts
  • Testes de responsividade e performance

Trabalhamos diretamente com HTML, CSS e JavaScript puros, sem uso de bibliotecas externas além da YouTube IFrame API.

2. Página Inicial (index.html)

Apresenta um carrossel customizado onde cada slide representa um ODS. Cada item inclui:

  • Imagem ilustrativa
  • Título e subtítulo com cores específicas via data-color
  • Texto descritivo
  • Botões de navegação para vídeos e fontes externas

O carrossel é controlado com lógica em app.js, onde cada clique manipula diretamente o DOM com appendChild e prepend. As transições são controladas por animações CSS.

3. Player de Vídeo Interativo (video-index.html)

Essa página carrega um vídeo específico para cada ODS, controlado por parâmetros na URL (ex: ?ods=3). O script video-script.js:

  • Busca o ODS na URL
  • Aplica cor e gradiente únicos na interface
  • Carrega automaticamente o vídeo correto do YouTube
  • Gerencia volume, reinício do vídeo e estilo dos botões

Toda a paleta visual muda com base no ODS ativo. A interface é moderna, com botões acessíveis, barra de progresso personalizada e integração visual completa.

4. Estilo e Visual

Utilizamos três arquivos de estilo:

  • styles.css: define layout da home, carrossel, botões e efeitos
  • video-style.css: animações de fundo, cores, player
  • style-contacts.css: aparência cyber, efeitos 3D e blur

As fontes são da família Poppins, garantindo uma leitura agradável e moderna.

5. Funcionalidades Especiais

  • Transições suaves: animações com keyframes CSS
  • Responsividade: adaptado a todos os tamanhos de tela
  • Gradientes dinâmicos: diferentes por ODS
  • Atualização visual via JS: sem reload da página
  • Link dinâmico para YouTube no botão “Abrir no YouTube”

6. Conclusão

O projeto atinge seu objetivo de maneira criativa e eficaz. Usar tecnologia e design para falar sobre os ODS é uma forma de transformar educação em experiência. Esperamos que este site inspire e informe quem o acessa, cumprindo o papel de formar uma sociedade mais consciente e sustentável.
